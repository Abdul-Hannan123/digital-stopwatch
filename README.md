# Web Stopwatch

A simple and stylish stopwatch built.  
This project includes a background image and custom image-based buttons for play, pause, and reset.

---

## Features
- Start / Pause / Reset functionality
- Custom UI with background image
- Image buttons for controls
- Real-time time tracking (hours, minutes, seconds, milliseconds)
- Responsive design

---

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
